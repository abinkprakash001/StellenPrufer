How to Install in Google Chrome

  1. Download & Extract: Click Download Chrome Extension (.zip) above and unzip the downloaded file.
  2. Open Chrome Extensions: Open a new tab, type chrome://extensions in the address bar, and press Enter.
  3. Enable Developer Mode: Turn on the Developer mode toggle in the top-right corner.
  4. Load Extension: Click Load unpacked (top-left) and select the extracted stellenpruefer_extension folder.
